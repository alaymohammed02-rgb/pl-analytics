# The `3D` branch

All the 3D work of PL Analytics lives here, apart from the football project's branch (owner asked 2 Nov 2026).

## What is 3D in this repository

| What | Where | Test |
|---|---|---|
| **Mujassam Studio**, a personal 3D editor (shapes, images, GLB / glTF / OBJ models, keyframe animation), installable on a phone | `studio-<12 random characters>/` (the source is its `index.html`), `tools/studio/make_artifact.py` | `tests/studio/t_studio.py`, `tests/studio/ui_studio.js` |
| **The club's stadium in 3D** behind Real Madrid's page (WebGL, with a drawn model as fallback) | `assets/stadium3d.js`, `assets/stadium-gl.js`, `assets/vendor/three-st3.js`, `tools/three/build.sh` | `tests/st3d/ui_st3d.js` |
| **Pitch in 3D** (Club shape and the Full-time story) | `assets/pitch3d.js` | `tests/p3d/ui_p3d.js` |

The notes on each are in `CLAUDE.md` (search "3D" and "Mujassam Studio").

## Rules

- Original code and design only. Do not copy another product's code, assets or look; keep every library's licence next to it (three.js: MIT, Draco: Apache 2.0).
- No key or secret in anything here. The studio is published openly (anyone who knows its address can open it).
- Nothing is claimed for a real phone or GPU unless it was measured on one; the sandbox only has a software renderer.
- Stage specific files; no force push.

## Pages

GitHub Pages serves the site from `main` only. The studio's address (`.../pl-analytics/studio-<random>/`) therefore keeps working as long as the folder stays on `main`. Work done on this branch reaches the site only when it is merged into `main`.
